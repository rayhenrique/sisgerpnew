# Product Overview

SISGERP is a municipal public financial management system (Sistema de Gestão de Recursos Públicos) for Brazilian municipalities. It manages revenues (receitas), expenses (despesas), categories, and generates financial reports.

## Core Modules

- **Dashboard**: Financial overview with period-based metrics
- **Receitas (Revenues)**: Revenue transaction management
- **Despesas (Expenses)**: Expense transaction management with classifications
- **Categorias (Categories)**: Hierarchical category tree (fonte → bloco → grupo → ação)
- **Classificação de Despesas**: Expense classification management
- **Relatórios (Reports)**: Report generation with scheduling, caching, and multiple formats (PDF, XLSX, CSV)
- **Admin/Usuários**: User management with RBAC (superadmin, admin, user roles)
- **Auditoria**: Audit log tracking
- **Configurações**: System settings

## Key Characteristics

- Brazilian Portuguese UI and content
- Multi-tenant architecture (organization-based)
- Role-based access control (RBAC)
- Audit logging for compliance
- Report scheduling and caching
- Responsive design
